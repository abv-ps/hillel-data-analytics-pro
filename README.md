# Hillel Data Analytics Pro

Repository containing practical assignments and projects completed during the Hillel Data Analytics Pro program.

This repository features a structured learning path that illustrates the data analytics workflow, from data collection and storage to transformation, validation, visualization, and business interpretation.

Through hands-on assignments and an end-to-end analytical project, it showcases practical applications of Python, SQL, NoSQL databases, statistics, and business intelligence.

## Course Program & Project Structure

| Modules | Technology / Topic | Key Skills & Deliverables |
| :--- | :---: | :--- |
| **01–11** | **Python** | Fundamentals, data processing, APIs, Pandas, visualization, statistics & LLM integration |
| **12–20** | **PostgreSQL** | Queries, aggregations, joins, CTEs, window functions & database design |
| **21**    | **MongoDB** | Document-oriented databases & NoSQL queries |
| **22, 23, 25–27** | **Power BI** | Data modeling, Power Query, DAX & interactive dashboards |
| **28–29** | **Tableau** | Advanced calculations, LOD expressions & visual reporting |
| **24** | **A/B Testing Project** | Statistical evaluation, data visualization, and business insights |

## End-to-end A/B Testing Analytics Project

An end-to-end analytical project evaluating the results of an experiment involving a new mobile application interface design.

The project combines:

* Python for data preparation and validation
* PostgreSQL for database design and analytical views
* Power BI for interactive reporting and visualization
* Statistical analysis and business interpretation

Project workflow:

1. Data preparation and cleaning
2. Database creation and transformation
3. Analytical data modeling
4. A/B test evaluation
5. Dashboard development
6. Business conclusions and recommendations
