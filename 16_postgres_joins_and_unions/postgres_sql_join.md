# Об'єднання таблиць у PostgreSQL

Практична робота присвячена об'єднанню даних із кількох таблиць реляційної бази даних за допомогою SQL-з'єднань.

На прикладі бази Chinook розглядаються аналітичні задачі, для розв’язання яких необхідно поєднувати інформацію про клієнтів, покупки, треки, жанри, артистів та країни.

Основні напрями аналізу:
- визначення доходу за музичними жанрами та країнами;
- дослідження купівельної активності клієнтів;
- пошук треків, які не брали участі у продажах;
- визначення артистів із найбільшим музичним каталогом;
- порівняння доходу за жанрами з урахуванням географічного розподілу клієнтів.

Мета — навчитися об'єднувати пов'язані таблиці та використовувати отримані набори даних для розв’язання комплексних аналітичних задач.
