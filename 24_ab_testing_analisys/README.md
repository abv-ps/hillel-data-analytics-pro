# Аналітичний процес оцінки результатів A/B тестування

> Фінальний проєкт, виконаний у межах курсу **Hillel Data Analytics PRO**.

## Про проєкт

Мета проєкту — побудувати наскрізний аналітичний процес (**end-to-end analytics pipeline**) для оцінювання результатів A/B тестування нового варіанта інтерфейсу мобільного застосунку.

Робота охоплює повний цикл підготовки та аналізу даних: від дослідження початкового набору й очищення даних до побудови реляційної бази даних, створення SQL-представлень та інтерактивного звіту в Power BI.

Основний акцент зроблено на поєднанні інструментів Python, PostgreSQL та Power BI в єдиному аналітичному процесі.

## Постановка задачі

Необхідно проаналізувати результати A/B тестування та оцінити вплив нового варіанта інтерфейсу на конверсію користувачів.

Дані містять інформацію про:
- користувачів та їхні характеристики;
- розподіл користувачів між контрольною і тестовою групами;
- країни та типи пристроїв;
- щоденну активність і факт конверсії.

---
Під час аналізу досліджуються:

- загальна конверсія;
- конверсія тестових груп;
- поведінка користувачів за країнами;
- поведінка користувачів за типами пристроїв;
- часові зміни конверсії;
- статистична значущість отриманих результатів.

# Етапи виконання

## 1. Дослідження та підготовка даних
Початковий набір даних отримано у форматі Excel. Роботу з ним виконано в Python за допомогою Pandas.

На цьому етапі:
- досліджено структуру таблиць і типи даних;
- перевірено пропущені та некоректні значення;
- перевірено зв'язки між таблицями;
- виявлено та оброблено дублікати;
- підготовлено дані до завантаження в PostgreSQL.
Для дослідження даних та візуалізації окремих показників використано Matplotlib і Seaborn.


## 2. Проєктування та створення бази даних

Для зберігання підготовлених даних створено реляційну базу даних PostgreSQL.

За допомогою SQL-скриптів підготовлено структуру таблиць, визначено первинні та зовнішні ключі, а також обмеження цілісності даних.

Створення та адміністрування бази даних виконувалося через pgAdmin 4.

---

## 3. Завантаження даних до PostgreSQL

Підготовлені в Python таблиці завантажуються до PostgreSQL за допомогою SQLAlchemy та Psycopg2.

Це забезпечує перехід від первинної обробки даних у Python до подальшої роботи з реляційною базою даних.

---

## 4. Побудова SQL Views

Для підготовки даних до передачі в аналітичну модель створено SQL-представлення (Views).

Views використовуються для:

- об'єднання таблиць;
- агрегації показників;
- розрахунку допоміжних показників;
- підготовки оптимальної структури для BI-моделі.

---

## 5. Побудова аналітичної інтерактивної моделі Power BI

Power BI підключається до PostgreSQL та використовується для побудови інтерактивної аналітичної моделі.

У звіті реалізовано:
- показники та розрахунки за допомогою DAX;
- обчислювані стовпці та міри (calculated columns and measures);
- інтерактивні фільтри;
- аналіз показників за країнами та типами пристроїв;
- сторінки деталізації сегментів користувачів;
- перехід до деталізованих сторінок (drill-through);
- інтерактивні матриці та умовне форматування;
- динамічні заголовки, які змінюються залежно від вибраних фільтрів.
Для перегляду основних сторінок звіту без встановленого Power BI Desktop у директорії assets/ збережено знімки екрана.

### Запуск проєкту
#### 1. Підготовка середовища
Створіть віртуальне середовище Python та встановіть залежності:
> pip install -r requirements.txt
#### 2. Налаштування підключення до PostgreSQL
Створіть локальну копію .env.example з назвою .env та заповніть параметри підключення до PostgreSQL.
Файл .env містить локальні облікові дані та не повинен додаватися до Git.
Файл config.py зчитує параметри підключення з .env за допомогою python-dotenv.
#### 3. Створення бази даних
Створіть базу даних PostgreSQL та виконайте скрипт:
> sql/Project_data_analytics_create_table.sql
Він створює необхідні таблиці та обмеження цілісності.
#### 4. Запуск ноутбука
Відкрийте notebook/Project_data_analytics.ipynb у Jupyter Notebook або JupyterLab.
Ноутбук виконує підготовку та очищення даних, а також завантаження їх до PostgreSQL.
#### 5. Створення аналітичних представлень
Після завантаження даних виконайте SQL-скрипт:
> sql/Project_data_analytics_views.sql
Він створює представлення, які використовуються в Power BI.
#### 6. Перегляд звіту Power BI
Відкрийте файл:
> power_bi/Project_data_analytics_dashboard.pbix
За потреби налаштуйте підключення до власного екземпляра PostgreSQL.

# Основні результати

У результаті виконання проєкту реалізовано повний аналітичний процес — від підготовки та очищення даних до створення інтерактивної BI-моделі.

Інтерактивний звіт дозволяє аналізувати результати на різних рівнях деталізації та підтримує прийняття обґрунтованих бізнес-рішень щодо впровадження нового варіанта інтерфейсу.
