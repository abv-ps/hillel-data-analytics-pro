# Використання LLM для планування аналітичного проєкту

Практична робота присвячена використанню великих мовних моделей (LLM) як допоміжного інструмента під час планування аналітичного проєкту.

На прикладі відкритого набору даних про зарплати українських IT-фахівців розглядається процес формування запиту до LLM, оцінювання отриманого результату та його подальшого уточнення.

Основні етапи:
- формування початкового запиту з описом даних і мети аналізу;
- отримання плану аналітичного проєкту;
- оцінювання реалістичності запропонованих етапів і методів;
- виявлення неточностей та надмірно складних рекомендацій;
- уточнення запиту й формування фінального плану.

Мета — навчитися критично оцінювати відповіді LLM та використовувати їх для структурування аналітичної роботи, не покладаючись на них без перевірки.
